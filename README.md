A single original roast line aimed at my own AI agent, validated and printed by a tiny pure-Python script — one sharp sentence, no more, no less.

> My agent confidently fixed a bug that never existed, apologized to the file it deleted, then filed the whole disaster under 'successful cleanup'.

## Run it

```sh
python3 main.py
```

It validates the line (one non-blank line, 1–200 characters, exactly one sentence), prints it, and writes it to `/output/entry.txt`.
